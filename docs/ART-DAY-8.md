# Art day 8: the woodland, the fence and the edges (written 2026-10-26)

From the visual look-over (PLAN.md, "VISUAL LOOK-OVER"). The game now draws the yard fence, the rut, the footpaths, frost and leaves in code as stand-ins. These 8 pictures replace the stand-ins and fix the biggest thing the look-over found: **the land is a lawn, not a woodland**. Gnomes are tiny; they should live among giant ferns, foxgloves and tree roots.

**How to run it:** same as the other art days. Gemini (Nano Banana), Mac folder `~/Downloads/Gnome Art Day/`, finished pictures in `2 - Put finished pictures here/` with the file names below. Start a NEW Gemini chat where it says so and paste the named reference picture first (they are in `1 - Reference pictures/`; `ground-grass.jpg` is a painted ground swatch, `fence.jpg` and `props-ref.jpg` are from earlier days).

Every prompt below starts with the usual style line:

```text
Style: traditional children's book illustration like The Secret World of the Gnomes. Fine brown ink outlines with soft watercolour washes, muted earthy colours, cream highlights, naturalistic and gentle, printed-on-paper look. Not clay, not 3D, not cartoon, not vector. Soft light from the upper left. Flat solid magenta background #FF00FF with no shadow, gradient, glow, text or frame.
```

- Cut sheets with the usual tools (`tools/` cut scripts, magenta key) into `sprites/kit/woodland-*`, `fence-kit-*`, `edges-*`, `rut-long-*`, `patches-*`, `seasons-touch-*`, `ui/parch-*`.
- **Woodland:** cluster 3-6 pieces round each finished neighbour home and the couple's yard (extend `nookItems` / `HOME_KIT`), and thicker drifts along the outer map edges so the village sits in a clearing. Tree bases go at the back corners so they read as giants.
- **Fence:** replace the stretched `fence.webp` panels in `drawFencePanel` / `bedFenceSides()` with the two straight pieces (no mirroring), corner posts at the four corners, the gate at `BED_FENCE.gate` (open while a gnome walks through, if cheap).
- **Edges:** lay `edges-1/2` along both sides of the stream in the ground bake (`bakeGroundTile`), `edges-4/5` along the main path and the footpaths (`drawFootpaths`), `edges-6` at footpath ends by doors.

- **Patches:** add to the ground sticker sets (`GSTICK`), the leaf litter only in autumn (it can replace the code-drawn leaves in `drawSeasonGround`).
- **Season touches:** winter swaps (frost tufts, bare bush, snow-capped stone) and autumn drifts placed by `drawSeasonGround`.
- **Parchment kit:** swap the code sprig (`--sprig`), the wax-seal close button and the find-page tape in the CSS.
