Tile edge naming: the diamond's four edges are top-left, top-right, bottom-left, bottom-right. Straight stream = top-left to bottom-right (batch 1). Straight path = top-right to bottom-left (batch 1). Bends: stream-bend-left = top-left to bottom-left, stream-bend-right = top-right to bottom-right, path-bend-top = top-right to top-left, path-bend-bottom = bottom-right to bottom-left. With the straight tiles these let a stream wind from the top-left of the map to the bottom-right and a path from top-right to bottom-left, and the crossing tile joins them.
