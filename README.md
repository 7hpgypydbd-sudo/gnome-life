# Gnome Life

A cosy fairy-garden game for iPhone, played as a web page (add to Home Screen from Safari).

- `index.html`, `game.js`, `content.js`, `sprites/` : the game (served by GitHub Pages from the repo root)
- `docs/` : PLAN.md, STYLE-GUIDE.md, ART-BATCH-1.md and reference art
- `tools/` : sprite-cutting scripts (need the local, untracked `cut/` working art)
